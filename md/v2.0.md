Summary of changes
giaCSat.c — new exported functions
Cbs_ManSolveWithState (the core new primitive):

Forces all nReg RO nodes to pRoVals[i] as permanent level-0 assumptions, then asks CBS to satisfy pTarget = 1. Because it lives inside giaCSat.c it can call the static internals (Cbs_ManAssign, Cbs_ManSolve_rec, Cbs_VarIsAssigned, Cbs_VarValue, Cbs_ManCancelUntil). If SAT, it reads RI fanin values from the assignment trail before cancelling them — that gives the next-state vector without needing a separate GIA pass. Returns 0/1/−1 (SAT/UNSAT/timeout), identical contract to Cbs_ManSolve.

Cbs_ManSetJustLimit — sibling setter for nJustLimit so callers stay opaque to Cbs_Man_t.

gia.h — declarations
Added Cbs_ManSetJustLimit and Cbs_ManSolveWithState to the public CBS API block.

cecClass.c — three functions replaced
Old	New
Cec_ManBuildFrameSat — Tseitin CNF builder	deleted
Cec_ManSatSimDfs — DFS with sat_solver + blocking clauses	Cec_ManCbsSimDfs — DFS with CBS
Cec_ManSimClassesSatGuided — orchestrator	rewritten to use CBS
Blocking clause replacement — CBS has no incremental clause API, so blocking is replaced by an FNV-hashed visited-state set (vSeen). Once a next-state hash is recorded, that state is not recursed into again, preventing cycles without modifying the GIA.

Two-direction targets — For each RI register j the DFS tries both RI[j]=1 and RI[j]=0 as CBS targets (controlled by CBS_DFS_MAX_RI = 8, so 16 total probes). The RI[j]=1 direction is UNSAT from the all-zero reset state on circuits where reset is a fixed point; the RI[j]=0 direction finds the trivially-reachable successor in those cases.

pRefs lifecycle — Cbs_ManSolve_rec calls Gia_ObjRefNum unconditionally for its fanout-based branching heuristic. The orchestrator now conditionally calls Gia_ManCreateRefs and tracks ownership (fCreatedRefs) to free it afterward only if it allocated it, leaving it intact when the caller already owns it.
